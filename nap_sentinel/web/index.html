Luces (Tesla)

    

      
Hace un destello de luces con la API de Tesla cuando hay un evento (por defecto solo de noche) para que la grabación se vea mejor.

      
    
        
  1. Solo la primera vez: crea en el navegador un marcador llamado sentinel.
          
    
          
    Cómo crearlo
            
    Android (Chrome): pulsa «Copiar marcador». Luego ⋮ → ☆ para guardar esta página y toca Editar:
              nombre sentinel; en la URL borra lo que hay y pega. Guarda.
    
            
    iPhone (Safari): pulsa «Copiar marcador». Luego Compartir → Añadir marcador y guarda. Abre
              Marcadores → Editar, toca el nuevo: nombre sentinel; en la dirección borra lo que hay y pega.
    
            
    Ordenador: arrastra este botón a la barra de marcadores: 🛡️ sentinel
    
            
          
    2. 
        

  2. 
          Se abre la web oficial de Tesla; tu contraseña se escribe allí, nunca aquí.
    3. 
        
  3. En la página de Tesla, antes de escribir tu email, abre el marcador: toca la barra de direcciones, escribe
          sentinel y toca la sugerencia con ☆ (iPhone: Marcadores → sentinel).
          Abajo aparece «Sentinel escuchando».
    4. 
        
  4. Inicia sesión. Volverás aquí solo y Tesla quedará conectado.
    5. 
      

      

      
¿No vuelve solo? Pegar el código a mano
        
Pega lo que muestra el recuadro de Sentinel en la página de Tesla. En un ordenador también vale:
          F12 → Red → clic derecho en la fila roja callback?code=… → Copiar → Copiar URL.
